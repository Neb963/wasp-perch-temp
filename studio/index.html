Getting real synthesis

  
The C engine was compiled once outside Perchance (Emscripten) and now ships inside this generator, so it loads on boot with no extra files. Inference and weights stay client-side; CI never saw them.

  
    
    
  1. Wait for automatic boot: Engine: WASM loaded then Engine ready (bundled src/wasm-dist/ + bundled src/models/edge/; Full loads on first switch to Full). If it fails, use Reload bundled engine or the fallback pickers.
    2. 
    
  2. Pick a voice/tag, type text, then Generate. Manual Import model folder/files remains as fallback/override only.
    3. 
    
  3. Maintainers — rebuild recipe: copy src/wasm/scl_bridge.c, src/wasm/build.sh, src/tools/wasm-build/github-workflow.yml → .github/workflows/build-wasm.yml, run Build SteerTTS WASM (source-only) (emsdk 3.1.68 + upstream 5008f8e0), replace src/wasm-dist/.
    4. 
  

  
Until the bundled engine + a model are ready, Generate is disabled with the reason shown — the studio will not fake audio (no speechSynthesis, no sample playback passed off as synthesis, no network inference).
